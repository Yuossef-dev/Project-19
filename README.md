# Federico Valverde | Official Website 🦅🏆

موقع شخصي وتصميمي مخصص للنجم الأوروغوياني **فيديريكو فالفيردي** (لاعب وسط ريال مدريد)، مصمم بطريقة عصرية (Modern & Clean Design) وداعم للغة العربية بشكل كامل مع واجهة مستخدم مظلمة (Dark Mode) مميزة تليق بشخصية وروعة اللاعب "إل فالكون".

---

## 🚀 مميزات الموقع (Features)

* **تصميم متجاوب بالكامل (Responsive Design):** شغال ممتاز على كل الأجهزة (موبايل، تابلت، ديسك톱).
* **دعم اللغة العربية (RTL):** اتجاه الصفحة RTL ومستخدم خط **Cairo** الجميل والمريح للعين.
* **أقسام تفاعلية ومتنوعة:**
  * **الرئيسية (Hero Section):** نبذة تعريفية سريعة مع صورة اللاعب وستايل مميز.
  * **البطولات (My Championships):** بطولات اللاعب مع ريال مدريد وإنجازاته.
  * **الإحصائيات (Career Stats):** أرقام ومعدلات مباريات فالفيردي.
  * **المسيرة (My Journey):** تسلسل زمني (Timeline) لأهم محطاته الكروية من أوروغواي لحد ريال مدريد.
  * **المعرض (Gallery):** لقطات وأبرز اللحظات المصورة.
  * **قسم الاقتباسات (Quote):** روح الجرينتا والقتال الخاصة بالفريق.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

المشروع مبني بـ Pure Technologies من غير تعقيد عشان يكون خفيف وسريع جداً:
* **HTML5**
* **CSS3** (Flexbox, Grid, Custom Variables & Media Queries)
* **Google Fonts** (Cairo Font)
